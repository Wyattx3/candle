# Infographic Builder

## When to use
A user wants a polished one-page infographic, poster, summary card, "stat sheet",
or shareable visual that combines headings, stats, icons, and short blurbs in a
designed layout. HTML+CSS gives full typographic and layout control; render it to
a crisp PNG with `sandbox_browser`. No image-generation API needed.

## Why HTML over PIL
HTML+CSS handles fonts, flexbox/grid layout, gradients, and spacing far better
than drawing each element in PIL. You design a page, then screenshot it.

## Step 1 — Design the HTML
`write_sandbox_file` to `/home/user/infographic.html`. Fix a poster-sized canvas
(e.g. 1080x1350 for portrait social, or 1200x1600). Inline all CSS. Use a clear
hierarchy: bold title, accent color, sectioned stats, generous whitespace.
```html
<!doctype html><html><head><meta charset="utf-8">
<style>
  * { margin:0; box-sizing:border-box; font-family: 'Segoe UI', system-ui, sans-serif; }
  body { width:1080px; height:1350px; padding:60px;
         background:linear-gradient(135deg,#0f172a,#1e3a8a); color:#fff; }
  h1 { font-size:64px; line-height:1.05; margin-bottom:8px; }
  .sub { color:#93c5fd; font-size:24px; margin-bottom:48px; }
  .grid { display:grid; grid-template-columns:1fr 1fr; gap:28px; }
  .stat { background:rgba(255,255,255,.08); border-radius:20px; padding:32px;
          backdrop-filter:blur(6px); }
  .num { font-size:56px; font-weight:800; color:#fbbf24; }
  .lbl { font-size:20px; color:#cbd5e1; margin-top:6px; }
  footer { position:absolute; bottom:48px; font-size:18px; color:#94a3b8; }
</style></head><body>
  <h1>State of the Agent</h1>
  <div class="sub">Candle runtime metrics, 2026</div>
  <div class="grid">
    <div class="stat"><div class="num">9</div><div class="lbl">built-in tools</div></div>
    <div class="stat"><div class="num">5</div><div class="lbl">memory tiers</div></div>
    <div class="stat"><div class="num">120s</div><div class="lbl">subagent budget</div></div>
    <div class="stat"><div class="num">64KB</div><div class="lbl">threat-scan cap</div></div>
  </div>
  <footer>Generated by Candle</footer>
</body></html>
```

## Step 2 — Render to PNG
1. `sandbox_browser` goto `file:///home/user/infographic.html`. Set the viewport
   to match the body size (e.g. 1080x1350) so the screenshot is full-page with no
   scrollbars.
2. `screenshot` to `/home/user/infographic.png`. Use a device-scale/zoom factor
   of 2 if the tool supports it for retina-crisp output.

## Design tips
- One accent color + one neutral palette; don't exceed ~3 hues.
- Big numbers for stats, small labels beneath — the classic infographic pattern.
- Use CSS grid/flex for alignment instead of manual positioning.
- Web fonts: load from Google Fonts via `<link>` for distinctive type, or stick
  to system fonts (they always render).
- Add icons as inline SVG or emoji; avoid external image deps that may not load
  offline.
- Leave breathing room — crowded infographics look amateur.

## Verify and deliver
1. `screenshot_analyze` the PNG to confirm nothing is clipped, text fits its
   boxes, and the layout matches the fixed canvas size.
2. `get_sandbox_file_url` on `/home/user/infographic.png`. Offer the `.html` so
   the user can edit copy and re-render.

## Gotchas
- Set the browser viewport to the exact body dimensions, or the screenshot will
  include whitespace or a scrollbar.
- `backdrop-filter` and web fonts need a moment to paint — wait briefly before
  screenshotting.
- If a Google Font is requested but offline, it silently falls back; verify the
  rendered type in the screenshot.
- Keep total height to a single "page" — if content overflows, the screenshot
  crops it. Increase the canvas height in CSS to fit.
